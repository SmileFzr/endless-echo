**🎮 直接开始玩：<https://smilefzr.github.io/endless-echo/>**　（当前版本 **v1.6.0**）

一个纯前端（零依赖、零构建）的 Roguelike 生存小游戏。手机、平板、桌面浏览器都能直接玩。

拖动屏幕控制角色移动，攻击全自动；击杀怪物掉落经验球，升级后三选一强化；
每 10 级刷新精英怪；地图上会随机出现传送商店；金币可以孵化生肖宠物。

## 在线试玩

### 👉 <https://smilefzr.github.io/endless-echo/>

手机浏览器打开后可"添加到主屏幕"，全屏当 App 玩。无需登录、无需安装。

> 进度保存在**各自设备**的浏览器里（`localStorage`），**不会跨设备同步**：
> 手机上的存档不会出现在电脑上，反之亦然。清除浏览器数据会丢失进度。

## 本地运行

不需要安装任何依赖，任选一种方式：

```bash
# 方式一：直接用浏览器打开 index.html（双击即可）
# 方式二：起一个静态服务器（推荐，避免个别浏览器的本地文件限制）
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 目录结构

```
.
├── index.html          # 页面结构（引入 css/ 与 js/）
├── css/
│   └── style.css       # 全部样式
├── js/
│   ├── utils.js        # 常量与工具函数（TAU / rnd / clamp / fmtTime ...）
│   ├── audio.js        # Web Audio 音频引擎：循环 BGM + 音效合成
│   ├── game.js         # 游戏状态、数值成长、战斗与推进逻辑
│   ├── pets.js         # 宠物表（生肖伙伴）
│   ├── skills.js       # 技能表与属性表
│   ├── render.js       # 全部 Canvas 绘制
│   ├── ui.js           # DOM 界面交互与主循环
│   └── blackhole.js    # 黑洞随机事件 + 回声小镇 + 特殊能力（手写模块）
├── versions/
│   ├── README.md       # 单文件版本归档说明
│   └── game3.2.html    # v1.5.3 的原始单文件（拆分来源）
└── tools/
    ├── split.py        # 从单文件版本拆分出 index.html / css / js
    ├── verify.py       # 校验拆分没有丢代码（逐行比对 + 语法检查）
    ├── smoke-test.js   # 用 DOM 桩在 Node 里跑运行时冒烟测试
    ├── stress-test.js  # 全技能 × 全变异的压力测试
    ├── audit-numbers.js# 数值审计（加成是否被重复计算）
    ├── test-visibility.js # 切后台暂停 / BGM 清理的回归测试
    └── test-blackhole.js  # 黑洞 / 小镇 / 特殊能力的回归测试
```

> `js/` 里的 8 个文件都是**经典 script**，按 `index.html` 中的顺序加载、共享同一个全局作用域，
> 顺序不能随意调换（数组里是依赖顺序：工具函数 → 音频 → 核心逻辑 → 数据表 → 绘制 → 界面 → 黑洞玩法）。

## 玩法说明

| 操作 | 说明 |
| --- | --- |
| 移动 | 按住屏幕任意位置拖动（虚拟摇杆），或键盘 `WASD` / 方向键 |
| 攻击 | 全自动，无需操作 |
| 升级 | 每次升级弹出三选一：新技能 / 技能升级 / 属性强化 |
| 技能 | 最多 6 个，每个可叠到 10 层；第 11 层触发**变异**（二选一改变机制） |
| 精英怪 | 每 10 级刷新一只，击杀后小怪永久增强，屏幕边缘有红色箭头指示 |
| 传送商店 | 地图上随机出现，用局内金币购买临时强化 |
| 宠物蛋 | 主菜单进入，用金币孵化随机生肖宠物，最多 2 只出战 |
| 暂停 | 右上角 ⏸ 按钮或 `ESC` |
| 音效 | 右上角 🔊 按钮开关 |
| 特殊能力 | 拿到后出现在 HUD 上，点按钮或按 `1` `2` 使用 |
| 小镇交互 | 靠近 NPC 按 `F` 或点底部"交谈"按钮 |

- **无尽模式**：活下去，越久越强。
- **挑战模式**：存活 15 分钟即为通关。

进度保存在浏览器 `localStorage`（键名 `endless_echo_save_v2`），主菜单与暂停界面都可以重置存档。

## 图鉴

主菜单点 **📖 查看图鉴** 进入。图鉴会记录你**遇到过**的怪物与宠物：

- **已经遇到过**：正常显示图标、名字与关键数值，点卡片看详情
- **还没遇到**：只显示一个灰色空框（❓ ???），不可点击

顶部会显示收集进度（宠物 x/12、怪物 x/7）。怪物条目包含 6 种普通怪与 1 种精英怪。

## 黑洞与回声小镇

满足条件后，荒野上会随机出现**黑洞**：

**出现条件**：至少拥有 **3 个技能**，且其中**至少 1 个技能达到 3 级**。
满足后每 **3~5 分钟**随机刷出一个黑洞，存在 150 秒，走进即被吸入。

黑洞出现时会弹出一条**醒目的提示横幅**（居中卡片，带紫色辉光和倒计时），
同时屏幕边缘出现**带白色描边的紫色箭头 + 距离读数**指向黑洞方向——
即使黑洞在视野外也能立刻知道往哪走。

- 三种边缘指引的颜色不同，避免混淆：
  **紫色 = 黑洞**、**金色 = 传送商店**、**红色 = 精英怪**。

**回声小镇**：一张与荒野完全不同的城镇地图（绝对安全——不刷怪、不掉血）。

- 用虚拟摇杆或 `WASD` 在石板路上走动，靠近 NPC 会出现交互提示
- 城南的 🚪 传送门可以随时离开，回到荒野
- 镇上有 5 位 NPC，头顶的 **❗** 表示有新委托、**✅** 表示可以交差

**任务与奖励**：所有委托都是"回主地图完成"的战斗任务，完成后再回来交差即可获得特殊能力。

| NPC | 任务 | 奖励 | 效果 |
| --- | --- | --- | --- |
| 🏹 猎手 阿岩 | 击杀 1 只精英怪 | 🪽 风之翼 | 5 秒内移速 +90%，冷却 14 秒 |
| 🔨 铁匠 老铸 | 击杀 30 只怪物 | 👟 踏空靴 | 2.5 秒无敌并穿过怪物，冷却 16 秒 |
| 🧭 旅行者 图娅 | 在主地图存活 120 秒 | 👁️ 鹰眼 | 被动：暴击率 +12% |
| 📖 学者 灰笔 | 本局累计 200 金币 | 🧲 磁石 | 被动：拾取范围 +60 |
| 🎩 镇长 索恩 | 在主地图存活 300 秒 | 🔥 熔炉 | 被动：所有伤害 +12% |

- 主动能力（风之翼 / 踏空靴）会在战斗 HUD 上显示为带冷却倒计时的按钮，也可以按 `1` `2` 键释放；
  冷却受"急速"属性影响。
- 已解锁的能力会保存在存档中，**重置存档时不会被清除**（任务进度同样保留）。
- 被动能力直接计入角色属性。

## 开发工具

改动源码后重新拆分与校验：

```bash
python tools/split.py          # 重新生成 index.html / css/ / js/（含所有修复补丁）
python tools/verify.py         # 校验：产物与期望一致、源码一行不丢、node --check 通过
node tools/smoke-test.js       # 运行时冒烟测试
node tools/test-blackhole.js   # 黑洞/小镇/特殊能力回归测试
node tools/test-e2e.js         # 端到端：主循环 + 真实事件驱动整条链路
node tools/test-visibility.js  # 切后台暂停回归测试
node tools/stress-test.js      # 全技能 × 全变异压力测试
node tools/audit-numbers.js    # 数值加成审计
node tools/check-ids.js        # DOM id 一致性
node tools/check-town-reach.js # 小镇 NPC / 出口可达性
```

### 试玩时的控制台快捷命令

进入游戏（点了「无尽模式」）后按 F12 打开控制台，可以直接用这些命令跳过前期：

```js
dbgBH()        // 立刻召唤一个黑洞（跳过"3 技能且 1 个到 3 级"的条件）
dbgGoto()      // 传送到黑洞旁边，一步进入小镇
dbgTown()      // 直接进城（不经过黑洞）
dbgSpecials()  // 解锁全部特殊能力，之后按 1 / 2 就能用
```

也可以手动构造条件：

```js
P.skills.push({id:'sword',lv:3,mut:null,cd:0}, {id:'bomb',lv:3,mut:null,cd:0});
G.bh.timer = 1;   // 1 秒后刷出黑洞
```

`tools/split.py` 顶部的 `SRC` 指向单文件版本 `game3.2.html`，需要按你的实际路径修改。

> 注意：`game3.2.html` 里的少量缺陷是**在 `tools/split.py` 的 `PATCHES` 表里修复的**
> （切后台暂停、BGM 定时器泄漏、永久强化重复计算、经验阈值等）。
> 重新运行 `split.py` 会自动带上这些修复；产物中 `js/blackhole.js` 是手写模块，不由拆分生成。
