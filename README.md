**🎮 直接开始玩：<https://smilefzr.github.io/endless-echo/>**　（当前版本 **v1.7.0**）

一个纯前端（零依赖、零构建）的 Roguelike 生存小游戏。手机、平板、桌面浏览器都能直接玩。

拖动屏幕控制角色移动，攻击全自动；击杀怪物掉落经验球，升级后三选一强化；
每 10 级刷新精英怪；地图上会随机出现传送商店；金币可以孵化生肖宠物。

## 在线试玩

### 👉 <https://smilefzr.github.io/endless-echo/>

手机浏览器打开后可"添加到主屏幕"，全屏当 App 玩。无需登录、无需安装。

> 进度保存在**各自设备**的浏览器里（`localStorage`），**不会跨设备同步**：
> 手机上的存档不会出现在电脑上，反之亦然。清除浏览器数据会丢失进度。

## 本地运行

不需要安装任何依赖，任选一种方式：

```bash
# 方式一：直接用浏览器打开 index.html（双击即可）
# 方式二：起一个静态服务器（推荐，避免个别浏览器的本地文件限制）
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 目录结构

```
.
├── index.html          # 页面结构（引入 css/ 与 js/）
├── css/
│   └── style.css       # 全部样式
├── js/
│   ├── utils.js        # 常量与工具函数（TAU / rnd / clamp / fmtTime ...）
│   ├── audio.js        # Web Audio 音频引擎：循环 BGM + 音效合成
│   ├── game.js         # 游戏状态、数值成长、战斗与推进逻辑
│   ├── elite-types.js  # 9 种精英怪的类型表（手写模块，最先加载）
│   ├── pets-extra.js   # 生肖宠物扩展表（兔/蛇/马/羊/猴/鸡/猪/牛）
│   ├── pets.js         # 宠物表（鼠/虎/龙/狗，并合并上面的扩展表）
│   ├── skills.js       # 技能表与属性表
│   ├── render.js       # 全部 Canvas 绘制
│   ├── ui.js           # DOM 界面交互与主循环
│   ├── blackhole.js    # 黑洞随机事件 + 回声小镇 + 特殊能力 + 图鉴（手写模块）
│   └── debug-cmds.js   # 控制台调试指令 dbg*（手写模块，最后加载）
├── versions/
│   ├── README.md       # 单文件版本归档说明
│   └── game3.2.html    # v1.5.3 的原始单文件（拆分来源）
└── tools/
    ├── split.py        # 从单文件版本拆分出 index.html / css / js
    ├── verify.py       # 校验拆分没有丢代码（逐行比对 + 语法检查）
    ├── smoke-test.js   # 用 DOM 桩在 Node 里跑运行时冒烟测试
    ├── stress-test.js  # 全技能 × 全变异的压力测试
    ├── audit-numbers.js# 数值审计（加成是否被重复计算）
    ├── test-elites.js   # 精英怪类型 / 专属机制 / 图鉴分类的测试
    ├── test-blackhole.js  # 黑洞 / 小镇 / 特殊能力 / 图鉴的回归测试
    ├── test-debug-cmds.js # 控制台调试指令是否都可用
    ├── test-visibility.js # 切后台暂停 / BGM 清理的回归测试
    └── check-antipattern.js # 静态检查 (x || 默认值) - dt 这类计时器陷阱
```

> `js/` 里的 12 个文件都是**经典 script**，按 `index.html` 中的顺序加载、共享同一个全局作用域，
> 顺序不能随意调换（依赖顺序：精英类型表 → 工具函数 → 音频 → 核心逻辑 → 宠物扩展表 → 宠物表
> → 数据表 → 绘制 → 界面 → 黑洞玩法 → 调试指令）。
> 注意 `elite-types.js` 必须排在最前、`pets-extra.js` 必须排在 `pets.js` **之前**
> （后者求值时要读取 `PETS_EXTRA`）。

## 玩法说明

| 操作 | 说明 |
| --- | --- |
| 移动 | 按住屏幕任意位置拖动（虚拟摇杆），或键盘 `WASD` / 方向键 |
| 攻击 | 全自动，无需操作 |
| 升级 | 每次升级弹出三选一：新技能 / 技能升级 / 属性强化 |
| 技能 | 最多 6 个，每个可叠到 10 层；第 11 层触发**变异**（二选一改变机制） |
| 精英怪 | 每 10 级刷新一只，击杀后小怪永久增强，屏幕边缘有红色箭头指示 |
| 传送商店 | 地图上随机出现，用局内金币购买临时强化 |
| 宠物蛋 | 主菜单进入，用金币孵化随机生肖宠物，最多 2 只出战 |
| 暂停 | 右上角 ⏸ 按钮或 `ESC` |
| 音效 | 右上角 🔊 按钮开关 |
| 特殊能力 | 拿到后出现在 HUD 上，点按钮或按 `1` `2` 使用 |
| 小镇交互 | 靠近 NPC 按 `F` 或点底部"交谈"按钮 |

- **无尽模式**：活下去，越久越强。
- **挑战模式**：存活 15 分钟即为通关。

进度保存在浏览器 `localStorage`（键名 `endless_echo_save_v2`），主菜单与暂停界面都可以重置存档。

## 十二生肖宠物

用金币孵化宠物蛋随机获得，最多同时带 **2 只**出战；宠物等级随玩家成长，
**达到 11 级自动变异**（获得第二条效果）。每只的技能与变异都做了区分：

| 生肖 | 技能 | 效果 | 变异 |
| --- | --- | --- | --- |
| 🐭 鼠 | 鼠窃 | 偷取金币，累计 10 枚掉落大经验球 | 【窃运】偷窃时 30% 额外掉小经验球 |
| 🐮 牛 | 蛮牛铁甲 | *被动*：减伤并提升生命上限 | 【铜皮】减伤翻倍 |
| 🐯 虎 | 猛虎扑食 | 扑向血量最高的敌人，击杀重置冷却 | 【余威】落点范围爆炸 |
| 🐰 兔 | 狡兔三跃 | 连续跃击三次，伤害递增 | 【月影】跃击期间无敌，落地延长 0.5 秒 |
| 🐲 龙 | 龙息 | 喷吐火焰，灼烧可叠加 | 【余烬】龙息结束留下 3 秒火墙 |
| 🐍 蛇 | 蛇吻剧毒 | 咬击并附加剧毒（持续掉血 + 放大后续伤害） | 【扩散】毒素传给 90 范围内的同伴 |
| 🐴 马 | 千里疾风 | *被动*：提升移动速度 | 【踏云】加成翻倍并留下残影 |
| 🐑 羊 | 祥和之息 | *被动*：持续回复生命 | 【暖阳】残血时回复翻倍 |
| 🐵 猴 | 灵猴妙手 | *被动*：每 3 秒为所有技能减 0.6 秒冷却 | 【分身】每 5 秒额外施放一次随机技能 |
| 🐔 鸡 | 金鸡报晓 | *被动*：提升暴击率 | 【晨鸣】额外提高暴击伤害 |
| 🐶 狗 | 忠犬护主 | *被动*：拦截靠近的敌方子弹并反弹伤害 | 【忠魂】反弹伤害 +100% 并穿透 |
| 🐷 猪 | 福猪拱财 | *被动*：击杀掉落更多金币 | 【财源】每隔一会掉落大经验球 |

## 图鉴

主菜单点 **📖 查看图鉴** 进入。图鉴收录**怪物**（宠物在「宠物蛋」界面里已有自己的图鉴，这里不重复）：

- **普通怪物**（6 种）：基础近战 / 高速突进 / 群体虫潮 / 远程射手 / 重装坦克 / 自爆单位
- **精英怪物**（9 种）：幽影 / 妖怪 / 僵尸 / 毛怪 / 吸血鬼 / 霸王龙 / 幽魂 / 树妖 / 石像鬼

规则：

- **已经遇到过**：正常显示图标、名字与关键数值，点卡片看详情
- **还没遇到**：只显示一个灰色空框（❓ ???），不可点击
- 顶部显示收集进度，共 **15** 条（普通 6 + 精英 9）

## 精英怪

每 **10 级**刷新一只，击杀后所有小怪永久增强（每杀一只精英，精英血量 ×1.10）。
生成时**随机抽一种类型**，外观、数值与机制都不同：

| 精英 | 特点 | 专属机制 |
| --- | --- | --- |
| 👹 幽影 | 基准型 | 会蓄力冲撞 |
| 🎭 妖怪 | 快而脆（血 ×0.85，速 ×1.30） | **瞬移**到你身边扑击 |
| 🧟 僵尸 | 慢而韧（血 ×1.20，速 ×0.75） | **死后半血复活一次**，并炸开一片毒雾 |
| 🦍 毛怪 | 厚实（血 ×1.70） | 挨打时有 25% 概率**把你冻住** |
| 🧛 吸血鬼 | 灵活（速 ×1.15） | **吸血**：持续回复自身生命，冲撞时更快 |
| 🦖 霸王龙 | 最强（血 ×2.40，伤 ×1.60，体型 ×1.55） | **咆哮**加速周围所有小怪 |
| 👻 幽魂 | 脆而极快（血 ×0.70，速 ×1.45） | **远程冰弹**，命中会减速你 2.5 秒 |
| 🌳 树妖 | 极肉极慢（血 ×2.10，速 ×0.62） | 周身**毒雾**，靠近持续掉血 |
| 🗿 石像鬼 | 坚实（血 ×1.55） | **石甲**：受到伤害 −40%，免疫减速 |

> 精英的血量用**圆环**环绕本体显示，不再是头顶的横条。

## 黑洞与回声小镇

满足条件后，荒野上会随机出现**黑洞**：

**出现条件**：至少拥有 **3 个技能**，且其中**至少 1 个技能达到 3 级**。
满足后每 **3~5 分钟**随机刷出一个黑洞，存在 150 秒，走进即被吸入。

黑洞出现时会弹出一条**醒目的提示横幅**（居中卡片，带紫色辉光和倒计时），
同时屏幕边缘出现**带白色描边的紫色箭头 + 距离读数**指向黑洞方向——
即使黑洞在视野外也能立刻知道往哪走。

- 三种边缘指引的颜色不同，避免混淆：
  **紫色 = 黑洞**、**金色 = 传送商店**、**红色 = 精英怪**。

**回声小镇**：一张与荒野完全不同的城镇地图（绝对安全——不刷怪、不掉血）。

- 用虚拟摇杆或 `WASD` 在石板路上走动，靠近 NPC 会出现交互提示
- 城南的 🚪 传送门可以随时离开，回到荒野
- 镇上有 5 位 NPC，头顶的 **❗** 表示有新委托、**✅** 表示可以交差

**任务与奖励**：所有委托都是"回主地图完成"的战斗任务，完成后再回来交差即可获得特殊能力。

| NPC | 任务 | 奖励 | 效果 |
| --- | --- | --- | --- |
| 🏹 猎手 阿岩 | 击杀 1 只精英怪 | 🪽 风之翼 | 5 秒内移速 +90%，冷却 14 秒 |
| 🔨 铁匠 老铸 | 击杀 30 只怪物 | 👟 踏空靴 | 2.5 秒无敌并穿过怪物，冷却 16 秒 |
| 🧭 旅行者 图娅 | 在主地图存活 120 秒 | 👁️ 鹰眼 | 被动：暴击率 +12% |
| 📖 学者 灰笔 | 本局累计 200 金币 | 🧲 磁石 | 被动：拾取范围 +60 |
| 🎩 镇长 索恩 | 在主地图存活 300 秒 | 🔥 熔炉 | 被动：所有伤害 +12% |

- 主动能力（风之翼 / 踏空靴）会在战斗 HUD 上显示为带冷却倒计时的按钮，也可以按 `1` `2` 键释放；
  冷却受"急速"属性影响。
- 已解锁的能力会保存在存档中，**重置存档时不会被清除**（任务进度同样保留）。
- 被动能力直接计入角色属性。

```bash

node tools/test-e2e.js         # 端到端：主循环 + 真实事件驱动整条链路
node tools/test-visibility.js  # 切后台暂停回归测试
node tools/stress-test.js      # 全技能 × 全变异压力测试
```

### 试玩时的控制台快捷命令

进入游戏（点了「无尽模式」）后按 **F12** 打开控制台。**先输入 `dbgHelp()` 可以列出全部指令**。

> ⚠️ 弹窗提示 "Don't paste code" 时，按提示输入 `allow pasting` 再回车即可。

**内容解锁** —— 不用慢慢刷

```js
dbgAllPets()      // 解锁全部 12 只生肖宠物（顺带送 9999 金币）
dbgHatch()        // 直接孵化一只还没解锁的宠物（看孵化动画）
dbgAllSkills()    // 拿满 6 个技能并全部升到 10 级
dbgAllSpecials()  // 解锁全部特殊能力（含被动）
dbgCodexAll()     // 图鉴全部点亮（普通 6 + 精英 9）
```

**数值与进度**

```js
dbgGold(20000)    // 给自己金币（默认 5000）
dbgLv(20)         // 直接升到 20 级（会弹升级三选一）
dbgLevelUp(3)     // 立刻弹 3 次升级三选一
dbgGod(true)      // 无敌 + 秒杀（不传参数则在开/关之间切换）
dbgHeal()         // 回满血 + 3 秒无敌
dbgKills(30)      // 击杀数 +30（推进 NPC 委托用）
```

**宠物与怪物**

```js
dbgPets('dragon','horse')   // 指定宠物出战（最多 2 只）
dbgPetLv(11)                // 出战宠物设为 11 级（自动变异）
dbgSpawn('tank', 5)         // 精确刷 5 只指定怪物
                            // 可用: normal/fast/swarm/ranged/tank/bomber
dbgSpawn('elite')           // 随机刷一只精英
dbgSpawn('elite:rex')       // 指定精英: 用 id 或中文名都行
                            // shadow幽影 yokai妖怪 undead僵尸 yeti毛怪 vampire吸血鬼
                            // rex霸王龙 wraith幽魂 treant树妖 gargoyle石像鬼
dbgKillElite()              // 秒掉场上精英（测圆环血条与掉落）
dbgClearFoes()              // 清空场上所有怪物
```

**场景跳转**

```js
dbgBH()      // 召唤黑洞（跳过"3 技能且 1 个到 3 级"的条件）
dbgGoto()    // 传送到黑洞旁边，一步进入小镇
dbgTown()    // 直接进入回声小镇
dbgShop()    // 立刻打开传送商店
dbgSeen()    // 查看图鉴当前已遇到的条目
dbgHelp()    // 列出以上全部指令
```

也可以手动构造条件：

```js
P.skills.push({id:'sword',lv:3,mut:null,cd:0}, {id:'bomb',lv:3,mut:null,cd:0});
G.bh.timer = 1;   // 1 秒后刷出黑洞
```

> 这些指令定义在 `js/debug-cmds.js` 与 `js/blackhole.js`，**只在控制台手动调用，不影响正常玩法**。
> `tools/test-debug-cmds.js` 会验证它们全部可用。

`tools/split.py` 顶部的 `SRC` 指向单文件版本 `game3.2.html`，需要按你的实际路径修改。

> 注意：`game3.2.html` 里的少量缺陷是**在 `tools/split.py` 的 `PATCHES` 表里修复的**
> （切后台暂停、BGM 定时器泄漏、永久强化重复计算、经验阈值等）。
> 重新运行 `split.py` 会自动带上这些修复；产物中 `js/blackhole.js` 是手写模块，不由拆分生成。
